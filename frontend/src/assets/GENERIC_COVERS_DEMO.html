ℹ️ Informations Techniques

🎯 Quand utiliser les images génériques?

Les images génériques s'affichent automatiquement quand:

  • ✓ Le livre n'a pas d'image de couverture
  • ✓ L'image n'arrive pas à charger (erreur réseau)
  • ✓ L'URL de l'image est invalide
  • ✓ L'image OpenLibrary n'est pas disponible

🚀 Avantages

  • ✓ Pas de dépendance sur les images externes
  • ✓ Chargement très rapide (CSS pur)
  • ✓ Apparence professionnelle et attractive
  • ✓ Entièrement responsive
  • ✓ Bonne accessibilité
  • ✓ Facile à personnaliser

🎨 Personnalisation

Pour modifier les couleurs, éditez simplement les dégradés CSS dans le fichier Reader.jsx:

.bk-cover-local.c1 {
  background: linear-gradient(135deg, #couleur1 0%, #couleur2 50%, #couleur1 100%);
}
